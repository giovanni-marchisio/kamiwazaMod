# KamiwazaMod

Currently just patches some addresses found [here](https://github.com/giovanni-marchisio/kamiwaza60fps).

### **Installation**

Place the dll here: `steamapps/common/Kamiwaza Way of the Thief/Kamiwaza/Binaries/Win64/`

if you are on linux, you have to add `WINEDLLOVERRIDES="dwmapi=n,b"` to the launch options

### **Known Issues**
The cutscenes are a little bit desynced

Using an item is now doubled (?), so basically, you'll use two items by pressing the button just once.
